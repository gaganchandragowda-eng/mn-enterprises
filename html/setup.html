1

Create Firebase Project

  • Go to console.firebase.google.com and sign in with your Google account
  • Click "Add project" → name it mn-enterprises → click Continue → Disable Google Analytics → Create Project
  • In the left sidebar: Build → Firestore Database → Create Database → choose Start in test mode → pick region asia-south1 (Mumbai) → Enable
  • In the left sidebar: Build → Authentication → Get Started → Email/Password → Enable → Save
  • Go to Project Settings (⚙️ gear icon) → Your Apps → Add App (web icon </>) → Register app as "mn-enterprises-web" → Copy the config
2

Paste Your Firebase Config

Copy the firebaseConfig object from Firebase and paste it below. It should look like this:

const firebaseConfig = { apiKey: "AIzaSy...", authDomain: "your-project.firebaseapp.com", projectId: "your-project-id", storageBucket: "your-project.appspot.com", messagingSenderId: "123456789", appId: "1:123456789:web:abc..." };
3

Set Admin Credentials

Set the username and password your admin will use to log into the dashboard.

4

Deploy to Vercel (Free)

  • Push this entire html/ folder to a GitHub repository. If you don't have git installed, download GitHub Desktop
  • Go to vercel.com → Sign in with GitHub → Click "Add New Project"
  • Import your GitHub repository → Vercel will auto-detect it as a static site → Click "Deploy"
  • Your site will be live at your-project.vercel.app in about 30 seconds 🎉
  • Add a custom domain (optional): Vercel Dashboard → Domains → Add your domain
⚡ Important: After deploying, add your Vercel domain to Firebase Authorized Domains: Firebase Console → Authentication → Settings → Authorized Domains → Add Domain
5

Test Everything

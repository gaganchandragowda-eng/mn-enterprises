# 🏬 M N Enterprises — Project Workspace

This directory contains the multi-page static website for **M N Enterprises** (Plumbing & Electrical Store, Bangarapet).

---

## 📁 Directory Structure

```
mn-enterprises/
└── html/                     # 🌐 Multi-Page Static Website (HTML5, CSS3, JS)
    ├── index.html            # Landing / Homepage & Specialties Showcase
    ├── about.html            # Store Story, Values & Hours
    ├── contact.html          # Contact Information & Inquiry Form
    ├── account.html          # Customer Account & Order Tracking
    ├── login.html            # Authentication (Google, Phone, Password)
    ├── admin/                # Admin Panel with Order Status & Live Hub
    │   └── index.html
    └── assets/               # CSS, JS modules, and image assets
        ├── css/
        ├── js/
        └── img/
```

---

## 🚀 Running the Website

* **Directory**: `mn-enterprises/html`
* **Development Server**: `python3 -m http.server 8080` (or open `html/index.html` directly in any browser)
* **Live URL**: [http://localhost:8080](http://localhost:8080)
* **Admin Panel**: [http://localhost:8080/admin/](http://localhost:8080/admin/) *(Password: `mn2024`)*
